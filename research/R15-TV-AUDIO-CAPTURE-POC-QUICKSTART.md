# R15 TV 即時繁體字幕 POC：最短測試步驟

> 這是研究分支的實驗測試版，不是正式發行版。最新 [第 58 輪建置](https://github.com/DickyR15/R15-TV/actions/runs/38143827319) 已成功並上傳 [POC-58 ZIP](https://github.com/DickyR15/R15-TV/actions/runs/38143827319/artifacts/11703957666)；已通過 Android TV APK 編譯、Whisper JNI 與 OpenCC 資產檢查。仍需在 TCL Google TV 實機確認音訊擷取、即時翻譯和 4K 播放效果。

## 安裝與第一次設定

1. 直接下載 [R15 TV Whisper Base Subtitle POC-58 ZIP（約 80 MB）](https://github.com/DickyR15/R15-TV/actions/runs/38143827319/artifacts/11703957666)。若連結過期，開啟[第 58 輪建置紀錄](https://github.com/DickyR15/R15-TV/actions/runs/38143827319)，在 Artifacts 下載 `R15 TV Whisper Base Subtitle POC-58`。舊版 POC-43 不含完整直播字幕入口，請勿用來驗證現在的 M3U／M3U8 功能。
2. 解壓縮後安裝 R15 TV-POC-leanback-arm64-v8a.apk。測試版套件名稱應為 com.dicky.r15tv.poc、顯示名稱為「R15 TV 字幕測試」，不會覆蓋既有 R15 TV 正式 App。若最新工作流失敗，先不要安裝。
3. 在測試版內重新載入 M3U／M3U8 播放清單；由於這是獨立測試 App，原 App 的清單與設定不會自動複製過來。播放器仍保留 MPV。
4. 先到 **主畫面 → 設定 → AI 字幕／語音設定** 下載 Whisper Base 多語模型。模型權重不在 APK 裡，而是直接下載到 App 私有儲存空間；APK 內含 `libr15whisper.so`，不會把約 148 MB 的 Base 權重打包進去。
5. 第一次翻譯時，Google ML Kit 也會下載英翻中模型。第一次下載需要網路；模型就緒後語音辨識與翻譯設計為本機執行，不需 API 金鑰或付費雲端翻譯。
6. 播放 M3U／M3U8 英文 F1 直播時，畫面右上角會顯示 **AI 字幕／語音設定** 按鈕。打開後按 **「啟動即時字幕測試」**，允許錄音權限及 Android 系統音訊擷取。MediaProjection 是擷取工作階段的系統授權，重新啟動擷取時可能再次詢問。

## 4K 播放策略

到 **設定 → 播放器設定 → 解碼設定 → EXO／HLS 畫質策略**，可切換「自動適應（建議）／最高畫質」。預設自動適應不會強制選最高碼率；若 HLS/M3U8 清單有多種畫質，播放器可依實際頻寬調整。單一固定 4K 串流／檔案不會被轉碼，因此若卡頓來自硬體解碼效能，仍需更換來源的 1080p 版本或確認 MPV/EXO 解碼能力。若 MPV 明確回報不支援的解碼格式，測試版會直接嘗試改用 EXO 播放該來源。若單一路徑 4K 仍掉幀，需要依 codec、碼率和實際解碼器再診斷。

## 怎樣判斷測試結果？

- 音量數值會隨播放聲音變化，表示可能擷取到音訊；還必須看是否有英文辨識文字，再觀察繁體中文字幕。
- 若長時間貼近 -120 dBFS、完全沒有英文文字，先記下狀態訊息；這時不要急著換模型，應先調查電視韌體是否允許擷取 MPV 音訊。
- 若英文文字出現、中文未出現，查看 ML Kit 翻譯模型是否正在下載或報錯。
- ExoPlayer 的 HLS 自適應碼率現在不再強制選最高碼率，網路／來源不穩時可能先選較低畫質，再視吞吐量提升；這是為了減少卡頓，不會把影片永久鎖在低解析度。單一固定 4K 串流則不會因這項變更自動降碼率。
- 若 MPV 對某個來源發生硬解、軟解的解碼錯誤兩次，最新測試版會暫時改由 ExoPlayer 播放該來源並顯示提示；原本的 MPV 偏好不會永久改掉。這是針對「解碼錯誤」的備援，不會自動修復單純因渲染造成的掉幀。對固定單路 4K 或持續卡頓的來源，仍需看播放錯誤／影格統計判斷根因；不會為了字幕把所有影片永久改成軟解或鎖低解析度。
- 若字幕明顯落後直播、音訊卡頓或電視變慢，記錄延遲、運作時間與狀態；這些數據會用來決定是否要調整 Base 視窗或之後比較 Small 量化版。
- 測試完成按同一個按鈕停止字幕；主播放音量、聲道與播放流暢度不應受到明顯影響。

## 重要限制

目前的 POC 先使用多語 Whisper Base；Whisper Small 量化版是依據實機效能與準確率結果再決定，不會先行塞入第一版。成功建置 APK 仍不等於已完成 Google TV 實機驗收；音訊擷取、延遲、翻譯品質及長時間穩定性都需要在電視上測試。
